Begreber

TFM
Timefaktor: indtægtsført omsætning delt med lønomkostning
TFM EAC
Forventet TFM ved projektets afslutning
POC
Færdiggørelsesgrad: indtægtsført omsætning delt med baseline
DB og DG
Dækningsbidrag er omsætning minus eksterne omkostninger og løn. DG er DB i procent af omsætning.
WIP
Positiv: udført arbejde, der ikke er faktureret. Negativ: faktureret forud for arbejdet.
PL og PA
Projektleder og projektansvarlig (PM og PO i ERP-udtrækket)
ETC dage
Dage fra seneste ETC-opdatering til udtræksdatoen
Fokus
Følger projektnummeret fra måned til måned, til du fjerner det
Noter
Gemmes som en log pr. projektnummer og månedsluk, så du kan se, hvad du skrev sidst

Indstillinger

Eksportér mine data

Alt det, du selv har lagt oven på udtrækkene: noter, opfølgninger, fokus, projektbeskrivelser og lokationer, flaggrænser samt tilbud, bid/no bid, ændringer, kvalitetsplan, milepæle og dokumentlinks, når de findes. Projektnavn, BU, PL og PA kommer med, så filen kan læses alene.

Kort

Åbnes dashboardet fra GitHub Pages, bruges OpenStreetMap uden nøgle. Fra en lokal fil hentes kortbaggrunden fra CARTO og kræver en gratis nøgle. Den bestilles uden konto på carto.com/basemaps/apikey og kommer på mail. Erhvervsbrug er gratis op til 1 mio. kortfliser om måneden. Nøglen gemmes kun i denne browser.

Database og login

Dashboardet bruger databasen NIRAS Projektstatus i Supabase (EU). Kun e-mails i tabellen adgang kan se data. Nye brugere oprettes i Supabase under Authentication > Users og tilføjes med insert into public.adgang (email) values ('navn@niras.dk');
